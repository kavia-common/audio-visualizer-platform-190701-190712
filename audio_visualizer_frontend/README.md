# Audio Visualizer Frontend (React)

React app with authentication screens (login/signup), dashboard, and audio visualizer (file or microphone input) using WaveSurfer.

## Setup

- Copy `.env.example` to `.env` and set:
  - REACT_APP_API_BASE=http://localhost:3001

## Run

- Install: `npm install`
- Start: `npm start`
- Open: http://localhost:3000

## Features

- Signup/Login via backend REST (JWT)
- Dashboard with profile and saved configurations list
- Visualizer with waveform (file/microphone)
- Save/Load/Delete visualizer configurations
